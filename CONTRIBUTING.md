# Contributing to Muse Vita

Muse Vita is an unofficial homebrew project created and maintained by
**Sam Dyatt** (`@msdyatt`). Contributions and security reviews are welcome.

- Read `AGENTS.md` before changing protocol, auth, or networking code.
- Create a branch and open a pull request with test evidence.
- Run `python3 -m unittest discover -s tests -v`.
- Never include private API keys, SDK tokens, paired device credentials,
  logs containing account information, or unauthorized SDK redistribution.
- Mark unverified Vita hardware behavior explicitly.
- Report security vulnerabilities privately to the maintainer rather than
  posting credentials or exploits in public issues.
